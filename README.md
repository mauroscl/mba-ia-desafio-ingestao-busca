## Configuracao de ambiente

Este projeto usa variaveis de ambiente para chaves e configuracoes.

1. Copie o template versionado:

```bash
cp .env.example .env
```

2. Preencha apenas os valores reais no arquivo `.env` local.

Notas:

- O arquivo `.env` real nao deve ser versionado.
- O arquivo `.env.example` deve ser versionado com placeholders para onboarding.
- Em caso de vazamento de chave, revogue e gere uma nova no provedor.
